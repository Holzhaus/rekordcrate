pub fn anlz_folder(audio_path: &str) -> String
Expand description

Folder where Rekordbox puts the analysis files of a track (ANLZ0000.DAT, .EXT and .2EX), relative to PIONEER/USBANLZ.

audio_path must be the absolute device path stored for the track, including its leading slash, for example /Contents/Artist/Album/Track.flac. Case, separators, and Unicode are significant; this function deliberately performs no path normalization. The returned path always has the form Pxxx/yyyyyyyy, using uppercase, zero-padded hexadecimal components.

The path is processed as UTF-16 code units by a custom rolling hash, reduced modulo 200003, which is the second component. Selected bits of that hash form the first.

Players have been seen to recompute this folder from the audio path instead of relying on the analyze_path stored in export.pdb (confirmed on the XDJ-XZ), so analysis files have to be placed here to be found.

The algorithm was contributed by AnnoyingTechnology from interoperability research published in December 2025.
