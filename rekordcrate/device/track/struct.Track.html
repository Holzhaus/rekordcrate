Expand description

A track as a user thinks of it: plain String fields, no foreign-key IDs. An empty string means “none”, as in the PDB itself.

DeviceExport::add_track takes one and DeviceExport::tracks hands them back. Fields not exposed here need a pdb::Track row driven directly via crate::pdb::io::Database.

§title: String

Track title.

§artist: String

Performing artist name.

§album: String

Album name.

§genre: String

Genre name.

§key: String

Musical key name (e.g. “Am”, “F#m”, “8A”), stored as given.

§label: String

Record label name.

§composer: String

Composer name.

§remixer: String

Remixer name.

§orig_artist: String

Original performer, distinct from artist (covers/reworks).

§comment: String

Free-text comment. Padded with trailing spaces when the row would fall under the minimum size some players need; trailing spaces are trimmed when reading back.

§isrc: String

ISRC, in rekordbox’s mangled format.

§lyricist: String

Lyricist name.

§mix_name: String

Remix/mix name.

§release_date: String

Free text. Rekordbox itself writes strict YYYY-MM-DD or empty here, but this field is passed through verbatim so callers can probe hardware behavior with arbitrary strings.

§date_added: String

Free text, commonly YYYY-MM-DD (see Self::release_date).

§file_path: String

Device-relative file path (e.g. /Contents/Artist - Title.mp3). Dedup key when non-empty.

§filename: String

File name without path.

§artwork_path: String

Device path of the artwork thumbnail (e.g. /PIONEER/Artwork/00001/a1.jpg), stored verbatim in the Artwork row. Empty = none. The caller owns placing the image files it names — or, with the artwork feature, gets a path whose files the export writes itself from DeviceExport::import_artwork.

§message: String

Track “message” field shown in Rekordbox.

§tempo: f32

Tempo in BPM; encoded to centi-BPM (× 100) in the PDB.

§bitrate: u32

Bitrate in kbps.

§sample_rate: u32

Sample rate in Hz.

§sample_depth: u16

Bits per sample of the audio file.

§duration_secs: u16

Playback duration in seconds. PDB field is u16 (ceiling ~18.2 h).

§file_size: u32

File size in bytes.

§track_number: u32

Track number within the album.

§disc_number: u16

Disc number.

§year: u16

Release year.

§play_count: u16

Number of times the track was played.

§rating: Rating

Star rating.

§color: ColorIndex

Color label.

§file_type: FileType

Audio file format.

§autoload_hotcues: bool

Whether stored hotcues auto-load on a CDJ. Maps to the PDB string "ON" / empty.
