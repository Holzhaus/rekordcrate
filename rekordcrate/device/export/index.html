DeviceExport: one handle to read a Rekordbox USB export, build one from scratch, or add to an existing one.

use rekordcrate::{DeviceExport, PlaylistTreeNodeId, Track};

let mut export = DeviceExport::create("/mnt/usb")?;
let track = export.add_track(&Track {
    title: "Song".into(),
    artist: "Artist".into(),
    file_path: "/Contents/Artist - Song.mp3".into(),
    ..Track::default()
})?;
let playlist = export.create_playlist("Warmup", PlaylistTreeNodeId::root())?;
export.add_track_to_playlist(playlist, track.id)?;
export.save()?;

for (id, track) in export.tracks()? {
    println!("{id:?}: {} - {}", track.artist, track.title);
}

This module never copies audio files into Contents or generates PIONEER/USBANLZ analysis files (ANLZ.*). Also, the API is append-only, existing rows cannot be updated or deleted. So if you want to make edits, you should either open the pdb files with pdb::io::Database::open (and thus deal with the format intricacies yourself) or re-add via a fresh export instead.

Layout describes where each of the export’s files lives on the device.
